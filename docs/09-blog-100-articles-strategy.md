# GingerControl 126 篇 Blog SEO 衝刺計畫

## Context

基於 Google Keyword Planner 實測數據、People Also Ask、自動補全關鍵字，以及現有網站架構，制定一周內發布 126 篇 blog 的 SEO 內容策略。目標是透過 **Topical Authority Clusters（主題權威叢集）** 快速建立搜尋引擎信任度。

### 核心關鍵字數據（Google Keyword Planner 實測）

| 關鍵字 | 月搜量 | 競爭指數 | 狀態 |
|--------|--------|----------|------|
| hts code lookup | 50,000 | 6 (低) | ✅ 已有產品頁 |
| tariff calculator | 5,000 | — | ✅ 已有產品頁 |
| customs software | 5,000 | 28 | ✅ 已加入 meta |
| automated commercial environment | 500,000 | — | ❌ 需要 blog |
| trade compliance software | 500 | 7 | ✅ 已加入 meta |

### 為什麼用 Topical Cluster 策略？

Google 不是看單篇文章排名，而是看 **整個網站對某個主題的覆蓋深度**。如果你有 1 篇 HTS 文章，Google 認為你是路人；如果你有 25 篇互相連結的 HTS 文章，Google 認為你是專家。100 篇文章分成 7 個叢集，每個叢集有 1 個 Pillar（支柱頁）+ 多個 Supporting（支撐頁），互相內部連結。

## 每篇文章的標準結構

```
1. Opening Paragraph（50-80 字）
   → 直接回答文章核心問題，讓 AI 引擎可以直接擷取

2. Table of Contents
   → H2 自動生成

3. Body Sections（3-6 個 H2）
   → 每個 H2 對應一個子主題/次要關鍵字
   → 包含表格、列表、數據等結構化內容

4. FAQ Section（3-5 個 Q&A）
   → FAQPage schema 標記
   → 問句來自 People Also Ask

5. CTA Section
   → 自然連結到對應產品或服務

6. Related Articles（2-3 篇同叢集文章連結）
   → 建立叢集內部連結
```

| 類型 | 字數 | 適用 |

## 內部連結策略（Critical for SEO）

每篇文章必須包含：
- **1 個連到同叢集 Pillar** 的連結（向上連結）
- **2-3 個連到同叢集 Supporting** 的連結（水平連結）
- **1 個連到產品頁** 的 CTA 連結（轉換連結）

### 叢集間互連範例
```
Cluster 1 (HTS) ←→ Cluster 5 (Industry)
  "HTS Chapter 84 Guide" ↔ "Machinery Import Guide"

Cluster 2 (Tariff) ←→ Cluster 3 (Country)
  "Section 301 Explained" ↔ "Importing from China"

Cluster 4 (ACE) ←→ Cluster 6 (Compliance)
  "CBP Focused Assessment" ↔ "Reasonable Care Guide"
```

## SEO 加速技巧（一周見效的實務做法）

### 1. Google Search Console 手動提交
每發布一篇文章，立刻到 Google Search Console 用 URL Inspection 手動提交索引請求。一天可提交 ~10-20 個 URL。

### 2. Sitemap 自動更新
Next.js 的 `sitemap.ts` 已經會自動從 blog API 生成 sitemap。確保 Google Search Console 已提交 sitemap URL。

### 3. 內部連結密度
首頁、產品頁、服務頁都應該有連到 blog 文章的連結。可以在：
- 產品頁底部加 "Related Articles" section
- FAQ 頁面的答案中連到深入文章
- 首頁 blog slider 展示最新文章

### 4. Schema Markup
每篇文章都自動有 BlogPosting + FAQPage schema（現有架構已支援）。

### 5. 標題優化
- 每個 H1 都包含主要關鍵字
- Meta title 55-60 字元以內
- Meta description 150-155 字元以內，包含 CTA 語氣
